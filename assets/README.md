# Assets — Green Science

Colocá aquí los archivos de marca y de producto. Claude Code los moverá a `/public` al construir el sitio.

## Logos (pendientes de subir)
Recomendado exportar/guardar:
- `logo-color.svg` / `logo-color.png` — logo full color sobre fondo claro (GREEN verde + SCIENCE azul + tagline).
- `logo-dark-bg.png` — versión para fondo oscuro (tagline en blanco).
- `logo-symbol.svg` / `logo-symbol.png` — solo el símbolo (hélice ADN + hoja).
- `favicon` — derivado del símbolo (32x32, 180x180 apple-touch, .ico).

> Tenés versiones del logo en color (fondo blanco), sobre fondo negro y solo-símbolo. Exportalas en SVG si es posible (mejor para web); si no, PNG en alta resolución con fondo transparente.

## Imágenes de producto (etiquetas / envases)
- Una imagen por producto (envase de 1 L / 20 L) para las tarjetas y el detalle.
- Nombrarlas por slug: `full-power-50.png`, `full-green-100.png`, `seed-forte-4-0.png`, `seed-forte-3-0.png`, `biomax-43.png`, `bioguard.png`, `bio-mulusk.png`, `biodyne-500.png`.

## Fotografía
- Fotos reales de campo/cultivos (soya, maíz, arroz, caña, banano) para hero y secciones.
- Si no hay fotos propias, usar imágenes con licencia adecuada; evitar stock cliché.
