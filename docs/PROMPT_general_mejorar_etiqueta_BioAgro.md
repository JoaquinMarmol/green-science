# Prompt general — Mejorar la etiqueta (image-to-image)

Un **único prompt** para todas. Subí la etiqueta ya generada (con sus textos, logos, foto y QR adentro) y pegá este prompt. No repite los textos (el generador ya los ve en la imagen): solo le pide **no cambiar nada del contenido** y **mejorar la terminación** para que quede más profesional. Al ser el mismo prompt para las 12, todas quedan parejas.

---

## PROMPT (copiar y pegar · va con la imagen adjunta)

```
Use the attached label image as the EXACT base. Keep it identical in content and layout, and only improve its visual finish so it looks like a professional, print-ready product label (a real bottle label): cleaner typography rendering, better contrast and legibility, subtle depth, soft shadows and gradients, refined spacing, a cohesive premium look.

STRICT RULES — do not break any:
- Do NOT change, translate, rewrite, add or remove ANY text. Keep every word, number and symbol exactly as it appears, in Spanish, with the same spelling.
- Keep ALL logos exactly as they are. Do NOT invent, redraw, restyle, move or replace any logo, icon, flag or QR code.
- Keep the same structure: three columns + bottom band, the same photo, the same accent color, the same sections in the same positions. Do not rearrange or resize the text blocks.
- Only enhance the visual quality and finishing — never the wording or the layout.

Output: the same label with the same texts and the same logos, just more professional, polished and high-resolution. Flat label, no watermark, no extra elements.
```

---

## Cómo usarlo
1. Subí **una** etiqueta (por ejemplo `Etiqueta_BioCore.png`) al generador.
2. Pegá el prompt de arriba.
3. Repetí con cada una de las 12, **con el mismo prompt** → todas quedan con el mismo estilo mejorado.

> Si notás que aún así cambia algún texto o el logo, agregale al final: *"If any text or logo would change, keep the original one untouched."* Y si el texto fino se sigue distorsionando, lo más seguro es mantener la base por plantilla (el PDF ya la tiene perfecta) y usar la IA solo para el acabado o el mockup del bidón.
