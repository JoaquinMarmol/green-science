# Prompts IA — Fondos y fotos vendedoras por producto (Green Science)

Prompts para generar con IA (Midjourney, DALL·E, Flux, Ideogram, etc.) un **fondo** para la ficha técnica o una **foto vendedora** de cada producto de la línea Green Science.

**Cómo usarlos**
- Los prompts están en **inglés** (los generadores rinden mejor). Copiá y pegá tal cual.
- Cada producto tiene **dos variantes**:
  - **(A) Fondo para ficha** → deja un lado limpio/desenfocado para poner texto y el bidón encima.
  - **(B) Foto vendedora** → escena más completa y protagonista, para redes/portada.
- Sacá **sin texto ni logos** (los agregás vos después). El negative prompt de abajo ya lo pide.
- Formato sugerido: **16:9 horizontal** (portada/ficha) o **9:16 vertical** (historias). Agregá `--ar 16:9` o `--ar 9:16` en Midjourney.

**Negative prompt (pegar en todos):**
```
no text, no words, no letters, no logos, no watermark, no captions, no UI,
no distorted plants, no extra fingers, not oversaturated, no cartoon, realistic
```

**Estilo base común (ya incluido en cada prompt):**
Professional agricultural photography, natural daylight, shallow depth of field, high resolution, photorealistic, clean composition, negative space on one side for text/product.

### Tips para que queden vendedoras
- Pedí **3–4 variaciones** y elegí la de mejor luz y composición.
- Para el fondo de ficha, dejá el bidón sobre el lado limpio (donde el prompt pide "empty space for text").
- Mantené una **misma paleta verde** entre productos para que la línea se vea coherente.
- Si el generador mete texto raro, reforzá el negative prompt o recortá esa zona después.
